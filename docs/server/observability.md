# Juris-AI — Add Grafana Data Source

## 1. Add Tempo datasource

### In Grafana:

```text
Connections
   ↓
Data sources
   ↓
Add data source
   ↓
Tempo
```

Grafana's current UI uses **Connections → Data sources → Add data source → Tempo**.

### Configure:

**Name**

```text
Tempo
```

**Connection URL**

```text
http://tempo:3200
```

**Authentication**

For our local setup:

```text
No authentication
```

Don't use:

```text
http://localhost:3200
```

because Grafana is running inside the `juris_ai_network`.

The networking is:

```text
Grafana container
      │
      │ Docker DNS
      ▼
tempo:3200
      │
      ▼
Tempo container
```

Your Compose already puts both on:

```text
juris_ai_network
```

---

**Save & Test**

Click:

`Save & test`

You should get something like:

```text
Data source is working
```

This is the first Grafana-side verification. Grafana documents **Save & test** as the validation step for a Tempo datasource.

---

### Go to Explore

Now:

```text
Explore
```

At the top-left datasource selector, choose:

```text
Tempo
```

You should see the Tempo query interface.

Choose:

```text
Search
```

Then:

```text
Run query
```

Grafana's Tempo quickstart follows this same flow: **Explore → Tempo → Search → Run query**, which lists recent traces.

You should now see traces generated by your `/chat` calls.

Something conceptually like:

```text
Trace ID                         Service       Duration
────────────────────────────────────────────────────────
6654758e0f6f01b327c4c9cc71e2312f juris-ai      2.9s
...
```

## 2. Add Prometheus datasource

### In Grafana:

```text
Connections
   ↓
Data sources
   ↓
Add data source
   ↓
Prometheus
```

### Configure:

**Name**

```text
Prometheus
```

**Connection URL**

```text
http://prometheus:9090
```

**Authentication**

For our local setup:

```text
No authentication
```

Don't use:

```text
http://localhost:9090
```

because Grafana is running inside the `juris_ai_network`.

The networking is:

```text
Grafana container
      │
      │ Docker DNS
      ▼
prometheus:9090
      │
      ▼
Prometheus container
```

Your Compose already puts both on:

```text
juris_ai_network
```

---

**Save & Test**

Click:

`Save & test`

You should get something like:

```text
Data source is working
```

This confirms that Grafana can communicate with Prometheus.

---

### Go to Explore

Now:

```text
Explore
```

At the top-left datasource selector, choose:

```text
Prometheus
```

Then run:

```promql
up
```

You should see:

```text
up{job="otel-collector"} 1
```

This confirms:

```text
Juris-AI
    ↓
OpenTelemetry Collector
    ↓
Prometheus
    ↓
Grafana
```
