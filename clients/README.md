# Clients

Reserved for future first-party client applications (web, mobile, CLI,
etc.) that consume the Juris AI API.

None exist yet. The server is a complete, usable product on its own —
a REST API with interactive documentation (Swagger UI at `/docs`,
ReDoc at `/redoc` once running) that any HTTP client can use directly.

See the root [README.md](../README.md)'s Repository Map for how this
directory fits into the overall layout, and
[CONTRIBUTING.md](CONTRIBUTING.md) for what adding a client here would
involve.
